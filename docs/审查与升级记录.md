### 2026-10-30：AI 助手教学技能专家评估

- **范围**：评估并重写“费曼式简化解释”“苏格拉底式提问”“代码审计式学习”三个 AI 教学技能。
- **主要问题**：原技能把输出格式当成学习发生；默认受众是成人开发者，不适配中学课堂；
  多技能同选时没有优先级；缺乏可观测指标与外部证据。苏格拉底式缺少挫败保护、
  一次一问与等待约束；费曼式类比无边界、不分学段；代码审计式依赖读文件，
  不适合聊天内即时使用。
- **重写结论**：把技能定位为“可被反驳的教学干预”。默认费曼式并按当前学段校准，
  固定解释结构、要求说明类比边界；苏格拉底式增加诊断起点、一次一问、等待、半步提示、
  卡住降级与安全例外；代码审计式改为聊天内结构，禁止编造文件与执行代码；
  明确多技能组合优先级、默认与空选语义。
- **验证**：pytest 覆盖技能注册、注入、默认/全选/不选、未知 id、客户端不可注入；
  真实浏览器 E2E 32/32。验收计划另含黄金题集、教师盲评、双评一致性（kappa≥0.6）、
  红队与前后测。
- **遗留**：内容质量与真实学习效果评估尚未执行，建议按黄金题集与课堂实验继续推进。

## 三、功能升级与整合

### 3.1 化学仿真（V6.1.0）

**用户看到什么**：新增「化学仿真」入口，三个标签：

- **绘制 + 3D**：左侧画化学结构（Ketcher），右侧实时显示 3D 分子；支持示例分子、
  `?smiles=` 教学深链、mol 文件保存、3D 截图与自动旋转；全程不联网。
- **可视化化学**：本地 21 个模型（晶体、周期表、分子结构、电化学、立体有机）。
- **分子库**：本地 27 个结构（小分子、有机物、晶体、生物大分子），Molstar 3D 展示。

**技术与许可**：Ketcher 3.18（Apache-2.0）+ Indigo WASM；OpenChemLib 9.26（BSD-3）
在浏览器 Worker 内生成 3D；3Dmol.js 2.5.5（BSD-3）渲染；Molstar 5.13.1（MIT）。
早期 JSME、在线检索、预置缓存与 MolDraw 在线嵌入均取消，改为完全离线自建。
新版 MolView 闭源不可嵌入；旧版因技术栈过旧未迁入。

**安全与限制**：编辑器/查看器在同源 iframe 中运行；只有编辑器帧放行 WASM/Worker 的
`unsafe-eval`，宿主页不放行；帧内 `connect-src` 收窄，阻断同源 API 调用；
本地上传文件只在浏览器内读取，不落服务器。离线 3D 适合常规有机小分子；
反应式、聚合物、超过 160 个原子会提示无法生成 3D（仍可 2D 绘制）；需要 WebGL
（Molstar 需要 WebGL2）。

### 3.2 硬件仿真（2026-11-02）

**用户看到什么**：新增「硬件仿真」入口，两个标签：

- **掌控板**：Blockly 积木图形化编程，积木转 MicroPython，2D 虚拟板运行；
  支持 Web Serial 把程序上传到真机（需 Chromium 内核 + HTTPS/localhost）。
- **ESP32-S3**：32 个虚拟实验，3D 开发板与引脚、固件代码阅读、沉浸模式、移动端适配。

**技术与安全**：两个应用本地化（约 42MB 含预压缩），字体自托管，保留 Apache-2.0
许可证；清除内置讯飞密钥；CSP 收窄到精确主机；数据按账号 uid 前缀隔离
（仅防同机换号混用，不是安全边界）。同源 iframe 存在理论信任边界，
彻底强隔离需要独立域名，残余风险已记录。

**升级**：回源重建、重打中文/uid 补丁、全量预压缩后重编安装包，体积约增 20–30MB。

### 3.3 铜匠实验室与调查问卷（2026-11-03，V6.1.0 已移除）

- **铜匠实验室**：曾内置 54 门高中科学 3D 实验课（物理 10 / 化学 25 / 生物 5 / 地理 14），
  分科标签、搜索、封面卡与课堂内嵌；许可是 CC BY-NC 4.0，**仅限非商业教学**，
  必须保留署名与许可。V6.1.0 已把铜匠实验室整体移出内置资源，升级迁移会删除
  旧资源及关联数据（不备份、不可恢复），需要保留请提前导出。
- **调查问卷**：新增 8 类题型（单选/多选/下拉/填空/多行文本/评分/矩阵单选/矩阵评分）、
  必答、填写时间窗、匿名问卷；结果页 Chart.js 图表与 CSV 导出。参考 SurveyKing
  v1.13.0（MIT）的题型与统计口径，原生重写，不引入 JVM、不复制代码。
- **安全**：课程走登录鉴权帧路由，slug 白名单防目录穿越，CSP `connect-src` 收窄；
  问卷仅创建者/管理员可管理，匿名结果不显示姓名。
- **验证**：pytest 535/535；全流程 E2E 31/31；铜匠 E2E 36/36；ruff、`.gz` 全过。

### 3.4 GeoGebra 与上传课件（V6.1.0）

- **`.ggb` 课件**：使用随包分发的本地 GeoGebra 5.4.934 引擎（offline 模式），
  课堂、资源卡与 `/study/link` 封装页均可打开，不访问 geogebra.org。
- **上传 HTML 课件**：统一经保留目录结构的镜像路由下发，子页面、模块、样式与数据
  使用短时只读凭证；上传目录保持 opaque sandbox，不获得平台同源权限。
- **GeoGebra 接管**：课件目录自带的 `viewer.html?file=...` 包装、或直接引用官网
  `deployggb.js` 的内联 applet，都会转交平台受信播放器；官网脚本改写为本地副本，
  `data:` 内联模块放行，纹理图片补 CORS，避免画布污染。
- **Worker 与局域网 HTTP**：opaque 帧的 Worker 由同源父页中继；局域网 HTTP 下
  用 `crypto.getRandomValues` 兼容缺失的 `crypto.randomUUID`。
- **返回**：封装页返回直接回到来源页/学习资源列表，不再用 `history.back()`
  受 iframe 联合会话历史影响。

### 3.5 学生“今日学习”、账号轨迹、管理总览（2026-11-20）

- **学生首页** `/student/home`：登录/改密/导航统一入口；聚合当前课堂、今日任务、
  时间轴、章节级学习路径与最近反馈；课堂结束给出明确提示。
- **账号轨迹**：记录登录时间/IP、退出时间、最后活跃、页面访问；同一账号多终端分别成行；
  页面轨迹只记顶层 HTML GET，不保存查询串；90 天自动清理；管理员可单条/批量删除，
  删除会写操作日志，当前登录会话不可删除。
- **管理总览** `/admin/dashboard`：部署检查清单（班级、学生、资源、课程表、仿真产物、
  预压缩、IP 归因、管理员口令、磁盘、备份、服务器时间、AI）与首次使用步骤。
- **菜单性能**：上传目录快照只做元数据扫描；文件列表与 AI 资源改为按需加载；
  快照 TTL 900 秒；新增超过 800ms 的“慢页面请求”日志。

## 四、安全与部署加固汇总

| 主题 | 关键措施 |
|------|----------|
| 私有文件 | 网盘/作业/提交/作品目录按账号与班级归属鉴权；拒绝双斜杠、点段、Windows 别名、8.3 短名等路径变体 |
| 课件访问 | 镜像路由 + 短时只读凭证（绑定资源、目录、来源与身份）；文件级“展示”隐藏；跨资源/点段/隐藏文件一律拒绝 |
| 沙箱 | 上传 HTML 默认 opaque；平台自有页面按来源动态同源；课件帧移除 `X-Frame-Options`/`frame-ancestors` 以允许 opaque 祖先嵌套 |
| CSP | 全站默认严格；课件帧按需放行 `data:` 脚本、WASM/Worker；化学编辑器/查看器单独收紧 `connect-src`；不使用通配符 |

## 六、升级注意事项

1. **先备份，再升级**：数据库用 `pg_dump`，同时复制 `static/uploads/`、`static/homework/`、
   `static/submissions/`、`static/question_img/` 和 `instance/secret_key`。
   只备份数据库会丢失附件与图片。
2. **V6.1.0 铜匠实验室删除**：升级迁移会删除旧「铜匠实验室」资源及关联的上课记录、
   活动、问卷与授权，**不备份、不可恢复**；如需保留请先导出。
3. **数据库结构自动升级**：应用启动时自动补表/补字段；不要自行降级数据库结构。
4. **Nginx 配置**：升级后确认 `/static/uploads/`、`/static/homework/`、
   `/static/submissions/`、`/static/chunks/` 仍代理回应用；否则上传文件鉴权会被绕过。
5. **预压缩 `.gz`**：Nginx 开启 `gzip_static` 时，升级后运行
   `python tools/precompress_static.py --refresh-only`，避免旧 `.gz` 覆盖新 JS/CSS。
6. **容器升级**：旧数据卷属主可能是 root，新容器以 UID 10001 运行；升级前按
   [容器部署指南](容器部署.md) 修正卷属主。
7. **管理员密码**：安装后第一次登录立即修改；忘记可用 `python tools/reset_admin_password.py`。
8. **账号轨迹**：默认保留 90 天；浏览器直接关闭不会产生准确退出时间，管理端显示
   “未正常退出/可能离线”，不会伪造时间。

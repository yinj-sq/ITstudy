识别规则说明

  • 题目按 【第N题】 切分
  • 文件夹名提取自「打开"XX"文件夹」（引号内，取最后一级）
  • py 文件名提取自「文件"xx.py"」（两端引号可省略）
  • 空数按 ①②③④ 统计（____ 兜底）
  • 分值：3 空 3/3/4，4 空 2.5×4，2 空 5/5，5 空 2×5，其他均分
  • 答案按文件夹名称分节（行首匹配，支持 91 / 91： / 【91】）
  • zip 按最后一级目录名匹配文件夹
输入三份材料后点击「开始识别」

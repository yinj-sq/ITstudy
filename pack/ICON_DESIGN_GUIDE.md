# 图标设计指南

适用版本：ITstudy v6.1.1
权利人：YINJUN
授权范围：仅授权个人使用，非商业用途

## 1. 应用图标

当前封装使用：

- `pack\assets\app.ico`：安装器、卸载器和应用展示图标。
- `pack\assets\app-icon-source.svg`：图标源文件，便于后续导出不同尺寸。

建议 `.ico` 文件包含以下尺寸：

- 16 x 16
- 24 x 24
- 32 x 32
- 48 x 48
- 64 x 64
- 128 x 128
- 256 x 256

设计要求：

- 小尺寸下仍能识别，16px 和 32px 不应糊成色块。
- 避免在图标中放大量文字，文字在小尺寸下不可读。
- 保持教育平台、信息科技、课堂管理等主题识别度。
- 背景透明，主体轮廓清晰，边缘不要贴满画布。
- 色彩应与项目界面协调，但不依赖单一深浅变化表达主体。

## 2. NSIS 位图

当前封装使用：

- `pack\assets\nsis-welcome.bmp`：欢迎页左侧图片。
- `pack\assets\nsis-header.bmp`：安装向导顶部横幅。

建议继续使用 NSIS MUI 兼容 BMP 规格：

- 欢迎页图片常用 164 x 314 BMP。
- 顶部横幅常用 150 x 57 BMP。
- 使用 24-bit BMP，避免透明通道兼容问题。
- 内容不要靠近边缘，预留安全边距。
- 不要把授权条款、操作说明或大段文字放进图片，文字应由安装向导页面承载。

## 3. 版本与版权标识

图标和位图中如出现版本或版权信息，应保持：

- 产品版本：v6.1.1
- 版权所有：YINJUN
- 授权范围：个人非商业使用

如果仅用于安装器背景装饰，建议不要把版本号写死在图片内，避免后续升级时重新出图。

Python填空题特殊标记使用指南

重要提示： 本系统现已支持使用特殊标记符号 (①, ②, ③ 等) 作为填空题标记，无需再使用 # YOUR ANSWER 标记。

教师指南 - 如何创建带特殊标记的Python填空题

可用的特殊标记

系统支持以下特殊标记符号作为填空位置：

  • ① - 填空1
  • ② - 填空2
  • ③ - 填空3
  • ④ - 填空4
  • ⑤ - 填空5
  • ⑥ - 填空6
  • ⑦ - 填空7
  • ⑧ - 填空8
  • ⑨ - 填空9
  • ⑩ - 填空10

使用步骤

  1. 创建Python代码文件，在需要学生填写的位置插入特殊标记符号（①, ②, ③...）
  2. 在系统中创建题目时，上传该Python文件
  3. 为每个填空位置设置正确答案：
    • 填空1对应特殊标记①
    • 填空2对应特殊标记②
    • 以此类推...
  4. 可以在特殊标记后添加注释，帮助说明该填空的目的或提示

示例代码

def is_prime(n):
    """判断一个数是否为素数"""
    if n <= 1:
        return ①  # 填空1: 预期答案为False
    
    if n <= 3:
        return ②  # 填空2: 预期答案为True

注意事项

  • 确保在设置答案时，填空编号与特殊标记编号一致
  • 系统会自动识别这些特殊标记，并与学生提交的答案进行比对
  • 可以接受多个正确答案，用竖线"|"分隔，如：True|true
  • 特殊标记可以用在表达式的任何位置，不仅限于整行替换

学生指南 - 如何回答带特殊标记的Python填空题

特殊标记的含义

在下载的Python文件中，你会看到特殊标记符号（如 ①, ②, ③），这些是需要你填写代码的位置。

回答步骤

  1. 下载题目文件
  2. 打开文件，找到所有特殊标记符号（①, ②, ③...）
  3. 直接将特殊标记替换为你的答案，保持其他代码不变
  4. 保存文件并上传

示例

原始题目
def is_prime(n):
    if n <= 1:
        return ①
    
    if n <= 3:
        return ②
正确提交的答案
def is_prime(n):
    if n <= 1:
        return False
    
    if n <= 3:
        return True
重要！ 请确保：
  • 直接替换特殊标记，不要保留标记符号
  • 不要修改标记以外的任何代码
  • 提交前确认文件可以正确执行

常见错误

错误类型 错误示例 正确做法
保留了特殊标记 return ① False return False
修改了其他代码 if n <= 0: return False 保持原始条件：if n <= 1: return False
答案格式不匹配 return "True" (字符串) return True (布尔值)

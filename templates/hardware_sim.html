硬件仿真

图形编程与 ESP32-S3 虚拟实验
Web Serial 上传与摄像头/麦克风需 HTTPS 或 localhost 新窗口打开

拖拽积木生成 MicroPython 代码，配合虚拟掌控板运行 2D 仿真；支持 Web Serial 上传真机。

图形编程仿真建议在桌面或横屏使用；手机可查看，但积木区与舞台较窄。

建议流程

  1. 先明确要解决的问题和成功标准，再动手。
  2. 运行前先写下预测：灯会怎么亮、屏幕会显示什么。
  3. 积木/接线一次只改一个条件，改完立刻运行对照。
  4. 把“现象—原因—结论”记录到学习单，再进入下一步。

认知支持

  • 先看积木，再切到代码视图，建立“积木 ↔ MicroPython/固件”的对应关系。
  • 复杂任务拆成 3–5 个小步骤，每步运行一次，避免工作记忆过载。
  • 用“预测—观察—解释”三栏记录，比只看运行结果更能形成概念。

课程与边界

  • 适用于信息科技“物联网实践与探索”“人工智能”等项目学习中的开源硬件实验。
  • 虚拟仿真不能替代真实硬件测量；结论要注明“仿真条件”。
  • 上传真机、摄像头、麦克风、定位需 HTTPS 或 localhost；局域网 HTTP 下仅仿真可用。
  • 本地工程按登录账号隔离，不跨设备同步；重要作品请导出/另存。

图片理解（视觉）
选择预设会自动填入上方 API 地址、模型并开启图片理解；API Key 仍需按对应平台填写。 国内模型均使用 OpenAI 兼容协议，型号与地址以官方文档为准。

开启后 AI 助手会把当前页面中的图片自动压缩后随消息发送给模型解读；仅对支持视觉输入的模型开启（如 DeepSeek Flash、GLM-5.3-Flash、MiniMax M3.1-Flash、GPT-4o、Claude 3/4 等）。不支持视觉的模型请保持关闭，界面会提示图片不会发送。

开启后，AI对话默认基于当前页面内容进行回答，用户可自行切换

教师端 AI

教师使用登录页的「只读模式」或「编辑模式」登录后都可使用 AI；关闭后教师端不显示 AI 助手，不影响学生端

开启后教师打开 AI 助手默认围绕当前页面内容回答，可在面板中自行切换；教师与管理员始终使用上方 API / 模型配置
教师编辑模式可在「教学资源 → AI 配置」填写自己的 API 地址和密钥；只读模式始终自动使用上方管理员 API 配置。未填写个人配置的编辑模式也会回退到上方配置。

安全说明
  • API Key 在服务端数据库中以 Fernet 密文保存
  • 用户端通过服务端代理访问AI，无法获取API Key
  • 每个学生的对话记录相互隔离
  • 管理员可随时关闭AI对话功能
  • 页面内容仅在用户选择时发送给AI

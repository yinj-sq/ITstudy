Notes
-----
- This directory is served as static assets; the application loads it with
  `applet.setHTML5Codebase('/static/geogebra/GeoGebra/HTML5/5.0/web3d/')`
  so GeoGebra never needs the public CDN in offline classrooms.
- Upgrade: download the bundle zip, replace deployggb.js and the
  HTML5/5.0/web3d + css directories, update this NOTICE, then run
  `tools/precompress_static.py` (full) and rebuild the installer.

    思维导图 · 使用说明

    第一次用，按这个顺序走一遍

    1. 双击中间那个框，把它改成这节课的主题
    2. 按 Tab 加一个分支，按 Enter 加同级
    3. 把节点拖到另一个节点上，它就换到那下面
    4. 按住 Shift 点两个节点，画一条跨分支关系——这是概念图区别于普通树状图的地方
    5. 课上点「放映」：投影模式放大字号，逐条展示让节点一个一个出现，两个可以一起开
    6. 课后点「自测」，或「文档 → 复制自测链接」发给学生（学生要能打开这个地址；双击打开时链接只在你自己的电脑上有效）

    想看每个按钮的完整说明和全部快捷键，切到「全部按钮与快捷键」那一页。

    要收集同行对这个工具的可用性评价，用 SUS 可用性问卷（10 题，约 3 分钟，可导出 CSV）。

    顶栏每个按钮是干什么的

    文档
    最近打开的图、导入别的工具做的图、复制、删除、把自测链接发给学生
    新建
    从一张白纸开始，或按「你要做什么」选一种图。菜单上写的是你要做的事，图型名在后面小字里
    版式
    节点怎么排。换成「左右分支 / 中心发散 / 上下分层 / 环形」等等，内容不动
    配色
    六套配色，以及连线用曲线还是折线
    放映
    放给学生看：投影模式放大字号，逐条展示按空格一个一个出现
    挖空
    把节点文字遮住，学生先回忆，你逐个揭示。按空格推进
    评估
    看这张图想得清不清楚：一句话结论 + 结构成熟度，想看细节再展开六个维度
    自测
    把界面换成学生端：一格一格问「这里应该是什么」，学生先写、再对答案、然后自评，最后看正确率。相似度只给一句提示（「很接近」），不判对错——中文表述千变万化，判分权交给学生自己
    导出
    图片放进课件、留白学案给学生填、备份文件、直接打印
    流程
    把一节课的五个动作串成一条路：新建 → 计时 → 挖空 → 评估 → 学案。可以跳着点，也可以随时关掉
    课堂节奏
    按阶段计时（结课 10 分钟 / 完整一课时 / 习题讲评），每段配一条元认知提示卡
    成熟度变化
    每次打开评估会记一笔，同一张图改动后再看，就能看到成熟度怎么变的——只和自己比

    编辑节点

    Tab
    添加子节点并输入
    Enter
    添加同级节点并输入
    F2 / 双击
    编辑当前节点
    Delete
    删除节点及其分支
    Ctrl + /
    折叠或展开分支
    方向键
    在节点间移动选中
    拖拽
    把节点拖到另一个节点上即可换父级
    Shift + 点击
    在两个节点间建立一条跨分支关系（含关系词）

    画布与展示

    滚轮
    缩放画布
    双指捏合
    触屏缩放（一体机 / 平板）
    空白处拖动
    平移画布
    Ctrl + 0
    适应窗口
    Ctrl + Z
    撤销（Shift+Z 重做）
    空格
    放映 · 逐条展示，或挖空时逐个揭示
    Esc
    退出展示 / 取消编辑

    放映菜单里是两个可以一起开的东西：投影模式把字号放大近两倍、去掉阴影并提高对比度，整张图看得清，专为教室最后一排设计；逐条展示让节点一个一个出现，按空格推进。两个一起开，就是「放大 + 逐个」。
    挖空把节点文字遮住，适合让学生先回忆、再逐个揭示。
    跨分支关系用来表达「导致 / 包含 / 对比 / 举例」这类语义，是概念图区别于普通树状图的关键；点那条线可选中，按 Delete 删除，双击可改关系词。
    导入文件支持 XMind（.xmind）、FreeMind（.mm）、OPML、百度脑图（.km）和 Markdown / 缩进大纲，也可以把文件直接拖到画布上；导入只搬结构和文字，别人的配色不会带过来。
